# Titanic Survival Prediction Using Machine Learning

## Project Overview
This project predicts whether a passenger survived the Titanic disaster using Machine Learning classification algorithms. It analyses passenger information to identify patterns associated with survival.

## Objectives
- Analyse the Titanic passenger dataset.
- Clean and preprocess data.
- Handle missing values.
- Convert categorical data into numerical features.
- Train and evaluate classification models.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn

## Machine Learning Algorithms
1. Logistic Regression
2. Decision Tree Classifier
3. Random Forest Classifier

## Installation

Install the required libraries:

```bash
pip install -r requirements.txt
```

## Run the Project

```bash
python "Titanic Survival Prediction Project.py"
```

## Evaluation Metrics
